# Taro.offDeviceMotionChange(callback)

[原始页面](https://taro-docs-7g1t02tzaeb163c4-1252004765.tcloudbaseapp.com/docs/apis/device/motion/offDeviceMotionChange)

取消监听设备方向变化事件，参数为空，则取消所有的事件监听。

支持情况：微信小程序 百度小程序 支付宝小程序 京东小程序 H5 ASCF元服务 React Native Harmony

> [参考文档](https://developers.weixin.qq.com/miniprogram/dev/api/device/motion/wx.offDeviceMotionChange.html)

<a id="类型"></a>

## 类型

```tsx
(callback?: Callback) => void
```

<a id="参数"></a>

## 参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| callback | `Callback` | 设备方向变化事件的回调函数 |
