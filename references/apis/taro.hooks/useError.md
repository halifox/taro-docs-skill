# Taro.useError(callback)

[原始页面](https://taro-docs-7g1t02tzaeb163c4-1252004765.tcloudbaseapp.com/docs/apis/taro.hooks/useError)

小程序发生脚本错误或 API 调用报错时触发的回调。

支持情况：微信小程序 H5 ASCF元服务 React Native Harmony Harmony hybrid

<a id="类型"></a>

## 类型

```tsx
(callback: (error: string) => void) => void
```

<a id="参数"></a>

## 参数

| 参数 | 类型 |
| --- | --- |
| callback | `(error: string) => void` |
