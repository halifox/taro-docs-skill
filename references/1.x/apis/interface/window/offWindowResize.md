# Taro.offWindowResize(callback)

[原始页面](https://taro-docs-7g1t02tzaeb163c4-1252004765.tcloudbaseapp.com/docs/1.x/apis/interface/window/offWindowResize)

取消监听窗口尺寸变化事件。

<a id="参数"></a>

## 参数

<a id="callbackres"></a>

### callback(res)

窗口尺寸变化事件的回调函数。

<a id="参数-1"></a>

#### 参数

<a id="object-res"></a>

##### object res

| Name | Type | Description |
| --- | --- | --- |
| windowWidth | `number` | 变化后的窗口宽度，单位 px |
| windowHeight | `number` | 变化后的窗口高度，单位 px |
