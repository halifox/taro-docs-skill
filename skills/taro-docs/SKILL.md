# Taro 中文技术文档

1. 优先使用用户指定的版本和目标平台。查阅现有项目时，可从 `package.json` 或锁文件确认 `@tarojs/taro` 的版本，并从构建命令或项目配置确认目标平台。版本或平台无法确定且会影响结论时，说明假设或请求澄清。
2. 在对应版本目录按文件名、API 签名或组件名搜索。4.x 位于 `references/`，搜索时排除其中的旧版本目录。旧版分别位于 `references/3.x/`、`references/2.x/` 和 `references/1.x/`。按主题浏览时查阅[完整目录](INDEX.md)，只打开与问题有关的文档。
3. 根据文档核对参数、返回值、平台支持和版本限制。涉及跨版本比较时分别核对各版本。回答时引用该页顶部的「原始页面」链接，区分文档明示的支持情况与推断。
