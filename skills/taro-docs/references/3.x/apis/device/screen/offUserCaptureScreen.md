# Taro.offUserCaptureScreen(callback)

[原始页面](https://taro-docs-7g1t02tzaeb163c4-1252004765.tcloudbaseapp.com/docs/3.x/apis/device/screen/offUserCaptureScreen)

用户主动截屏事件。取消事件监听。

支持情况：微信小程序 百度小程序 支付宝小程序 抖音小程序 京东小程序 H5 ASCF元服务 React Native Harmony

> [参考文档](https://developers.weixin.qq.com/miniprogram/dev/api/device/screen/wx.offUserCaptureScreen.html)

## 类型

```tsx
(callback: Callback) => void
```

## 参数
