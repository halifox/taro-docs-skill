# Taro.offNetworkStatusChange(callback)

[原始页面](https://taro-docs-7g1t02tzaeb163c4-1252004765.tcloudbaseapp.com/docs/3.x/apis/device/network/offNetworkStatusChange)

取消监听网络状态变化事件，参数为空，则取消所有的事件监听。

支持情况：微信小程序 百度小程序 H5 ASCF元服务 React Native Harmony Harmony hybrid

> [参考文档](https://developers.weixin.qq.com/miniprogram/dev/api/device/network/wx.offNetworkStatusChange.html)

<a id="类型"></a>

## 类型

```tsx
(callback?: Callback) => void
```

<a id="参数"></a>

## 参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| callback | `Callback` | 取消监听网络状态变化事件，参数为空，则取消所有的事件监听 |
